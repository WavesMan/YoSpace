# 前后台拆离约束清单（P2 准备）

## 目标
确保后台管理面板与博客前台在组件、样式、渲染能力层面低耦合，避免互相污染与回归风险。

## 目录与依赖边界
1. 后台页面仅从 `src/app/backend-core/**` 与 `src/server/**` 依赖业务模块。
2. 后台页面禁止直接依赖 `src/components/Blog/**` 与前台页面样式模块。
3. 可共享能力必须放入中立目录（建议 `src/utils/**`），禁止在前台组件目录中沉淀共享逻辑。

## 渲染与样式边界
1. 后台预览允许行为对齐前台，但组件实现保持独立。
2. 禁止后台页面复用前台容器级布局类（如博客页面容器、导航、背景层样式）。
3. 后台样式命名与模块文件保持 `backend-core` 下闭环，避免跨层覆盖。

## 评审检查项
1. PR 中若出现 `@/components/Blog` 在后台文件的新增引用，默认拦截。
2. PR 中若出现前台样式模块在后台文件的新增引用，默认拦截。
3. PR 必须包含 `tsc --noEmit` 与目标文件 eslint 通过记录。
4. 涉及编辑器/预览改动时，必须补充“多语种切换 + 保存回跳 + 预览渲染”回归说明。

## 回归基线
1. `zh-CN/en` 切换后，编辑字段与预览内容同步更新。
2. 保存成功后仅出现一次提示，刷新后不重复。
3. Tabs、Code、Mermaid、图片渲染在后台预览可用且不溢出容器。
