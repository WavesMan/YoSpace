# 全站加载与轻量过渡

本次以单一过渡替换原先的文章加载卡片、路由加载卡片及固定等待时间。加载层保留必要的语义结构，采用主题背景和短横线呼吸动画，不再显示转圈与多层提示卡片。

## 就绪条件和交互

- `PageReadiness` 统一处理所有内容页，只遮挡内容区域；导航和播放器位于屏障之外。
- 站内链接由 `TransitionLink` 的 Next.js `onNavigate` 回调报告导航开始。修饰键、外链、下载、锚点和被业务取消的导航不制造等待。点击当前路由可以取消尚未完成的导航。
- `loading.tsx` 仅登记 Suspense 等待，不渲染第二个占位卡片。页面通过 `usePageReadyTask` 登记正文或列表任务；任务集合变化时通知协调器，取消等待期间的逐帧轮询。
- 已登记任务完成后经过两帧提交布局即可显示，不再人为等待 520/620ms。内容和遮罩用 180ms 透明度过渡，无伪造百分比。15 秒未完成则显示重试入口，超时不当作成功。
- 每次路由或语言变化创建独立任务集合，旧任务的收尾不能关闭新页面遮罩。加载期间内容区域使用客户端 `inert`；服务端不输出该属性，确保禁用脚本时链接可用。
- 减少动态效果时取消动画；禁用脚本和打印时直接保留服务端内容。

## 内容和数据优化

正文段落和列表使用原生语义元素，一次呈现完整文字。代码和 Mermaid 保留完整排版，进入视口后最多执行一次 200ms 淡入，不再使用 Range 测量每个字形或逐帧修改 `clip-path`。代码高亮仍按需加载，点击和复制不会等待动画。图片改为 200ms 淡入，同屏最多四张、按 20ms 间隔轻微错峰。

Archive、Tags、Categories 和 Search 由服务端提供首批列表，客户端不重复拉取相同语言的初始数据。空列表同样属于有效初始结果。语言变化和分页请求支持取消，避免旧响应覆盖新内容；博客列表也补齐了这一处理。

文章系列与推荐在独立服务端 Suspense 边界输出，不再由文章页面直接 await 推荐列表。它们不登记正文就绪任务；服务端正文失败或语言切换时，保留原有客户端回退路径。默认播放器在浏览器空闲时加载，不阻塞正文。首页默认社交图标采用静态具名导入，其他自定义图标仍可动态加载并提供尺寸稳定的回退。

首页导航中的搜索属于局部交互，不登记全页就绪任务。进入导航页时准备文章索引，当前首页实例按语言复用已成功加载的索引（包括空列表），离开或切换语言会取消未完成的请求，失败可局部重试。引擎选中背景滑动，导航与站内面板以 180 毫秒淡出、淡入衔接，数量以 100 毫秒过渡，结果按文章 slug 保留身份并平滑增删、补位；不随每个字符重新挂载输入框，中文组合输入提交后才筛选。减少动态效果时直接更新。搜索栏位置固定，结果区独立滚动，滚轮、触摸和键盘操作不会被首页翻页手势拦截。外层使用 `overflow: clip`，避免装饰背景溢出后聚焦输入框使隐藏容器意外横向滚动。

列表索引按语言、文件名、修改时间、创建时间和大小判断版本，各分页共享解析结果；修改文件无需等 30 秒 TTL 才失效。详情缓存同样按具体文件版本失效，并限制缓存项数量。这是进程内缓存，不代表所有路由已经静态化，也不替代 CDN 缓存。

Markdown 仍保留现有的服务端 HTML 输出与客户端交互渲染方式，本次没有改成构建时预编译全文；此类改动需要单独比较 JavaScript 减少量与 RSC 数据体积，避免把解析成本变成更大的传输成本。

## 验证

```bash
pnpm test --run
pnpm lint
pnpm exec next build
```

浏览器脚本要求本机 Playwright 和 Chromium，可通过 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_BROWSER` 指定已有运行时。设置 `PRODUCTION=1` 后，各脚本启动独立端口并清理自己的临时样本和进程：

- `scripts/check-loading-transitions.cjs`：3004 端口，首页、正文、归档、标签、分类、搜索、博客列表与友链的单一过渡、首批列表无重复请求、可中断导航、减少动态效果及无脚本阅读。
- `scripts/check-home-search.cjs`：使用运行中的开发或生产服务（`HOME_SEARCH_BASE`，默认 `http://localhost:3000`），固定接口样本验证桌面、移动和短视口的搜索切换中间帧、慢请求不阻塞、索引复用、输入框稳定、结果滚动、中文组合输入、数量更新与减少动态效果；不依赖个人文章。可通过 `HOME_SEARCH_SCREENSHOTS` 指定现有目录保存截图。
- `scripts/check-page-loading.cjs`：3001 端口，屏外图表延后加载、代码高亮前后高度、复制全文、暗色与语言，以及无脚本回退；`SLOW=1` 支持 CPU 与网络限速。
- `scripts/check-responsive-layout.cjs`：3002 端口，九组尺寸、缩放、目录与固定页脚约束、归档居中及图片淡入。

个人 SemVer 文章只复制到本地工作区验证，不纳入提交。开发模式包含即时编译成本，性能判断以生产模式为准；本机合成样本观测不能直接换算成线上提速比例。
